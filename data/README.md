# Data

The datasets used in this project were obtained from publicly available UK data sources.

## Data Sources

The project combines multiple datasets relating to residential property transactions and location-based characteristics, including:

- UK residential property transaction data
- Postcode and geographic coordinate data
- Index of Multiple Deprivation (IMD) data
- Transport for London (TfL) station location data

These datasets were used to construct features including property characteristics, geographic location, deprivation level, distance to the nearest station, and distance from central London.

## Dataset Availability

The raw and processed datasets are not included in this repository due to their large file sizes.

The complete data preparation, preprocessing and feature engineering workflow can be found in the Jupyter notebook in the `notebooks/` directory.
